# Project overview

This documentation site describes the Mindcraft self-driving robot for the WRO Future Engineers 2025 competition. It contains:

- Design and 3D models (folder: `Models`)
- Bill of Materials and wiring (`otherfile/BOM.md`)
- Schematics and circuit files (`schemesfile/schemes.md`)
- Photos and videos (`t-photosfile/`, `v-photos/`, `videos/`)
- Source code overview and examples (`src/`)

Use the left navigation to explore each section.
